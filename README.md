# moex-market-report

Отчёт по рынку акций Мосбиржи на официальных данных: загрузка → хранилище → метрики → автономный HTML.

Данные — ISS Московской биржи (цены TQBR, состав и история индексов) и ЦБ РФ (курс USD). Никаких платных API.

## Быстрый старт

```bash
python -m venv .venv
.venv\Scripts\activate            # Windows
pip install -r requirements.txt

python ingest.py --from 2025-11-20 --to 2026-11-20   # скачивает и складывает в data/market.duckdb
python report.py                                     # output/market_report.html + CSV
pytest                                               # 18 тестов
```

Отчёт `output/market_report.html` автономен: графики встроены base64, открывается двойным щелчком, сети не требует.

## Что считает

| Метрика | Как считается | Зачем в резюме |
|---|---|---|
| Доходность за период | первая и последняя реальная цена | базовая нормализация |
| Годовая волатильность | σ дневных доходностей × √252 | риск |
| Максимальная просадка | падение от локального максимума | риск «в моменте» |
| Бета | cov(доходность, доходность индекса)/var индекса | относительная систематическая чувствительность |
| Корреляционная матрица | попарно, только по общим торговым дням, ≥60 наблюдений | диверсификация |
| Веса в индексе | ISS `analytics` на дату | концентрация |
| Оборот рынка | сумма `VALUE` по TQBR | ликвидность |

Ограничения намеренно показаны в самом отчёте: только ценовая доходность (без дивидендов), ETF в одной выборке с акциями, короткие истории не сравниваются с длинными.

## Архитектура

```
ingest.py   → moex.py, cbr.py   → data/market.duckdb      (слой хранения)
report.py   → metrics.py        → output/*.html, *.csv     (слой расчётов и визуализации)
tests/                          → pytest
```

- **DuckDB** выбран вместо Postgres: колоночная база, `INSERT OR REPLACE` идемпотентен, не нужен сервер — проект запускается одной командой на любом ноутбуке.
- **Идемпотентность**: повторная загрузка за пересекающийся период не дублирует строки (первичные ключи + `OR REPLACE`).
- **Журнал загрузки** `load_log` фиксирует каждый прогон: время, статус, объём — так отчёт можно привязать к версии данных.
- **ISS отдаёт формат по расширению пути, а не по `Accept`**: `/path.json`. Числа — строками с запятой. Оба подводных камня зашиты в `moex.py` и покрыты тестом `tests/test_metrics.py::test_num_parses_iss_formats`.
- **Пропуски не заполняются** ни нулём, ни последней ценой: строки склеены по датам реальных торгов, и бумага с короткой историей из расчёта выпадает, а не тянет за собой ложь.

## Тесты

```bash
pytest -v
```

Тесты проверяют формулы (доходность, просадка, бета, инфляция по Фишеру), устойчивость корреляции к неполным рядам и парсер чисел ISS. Сеть и база для тестов не нужны.
